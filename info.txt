```php
public function create(Request $request)
{
  $data = $request->only(['wacom_blob', 'nombre', 'dni', 'fecha_firmado']);
  
  // Validación DNI único - ERROR 422 si duplicado
  $exists = Firma::where('dni', $data['dni'])->exists();
  if ($exists) {
      return response()->json([
          'error' => "DNI ya registrado, por el usuario " . 
                     substr($data['nombre'], 0, 1) . "*****"
      ], 422);
  }
  
  // Guardar registro (backend NO desencripta)
  $firma = Firma::create([
      'nombre' => $data['nombre'],
      'dni' => $data['dni'],
      'fecha_firmado' => $data['fecha_firmado'],
      'wacom_blob' => $data['wacom_blob'],  // Guardado tal cual
  ]);
  
  return response()->json(['id' => $firma->id], 201);
}
```

3. CÓMO SE "DESENCRIPTA" - ARQUITECTURA REAL
====================================================================

⚠️ CLAVE DEL DISEÑO: El backend NO desencripta nada.
   Restricción: "El backend no intenta descifrar/encriptar/hashear; 
   solo valida unicidad de DNI y extrae metadatos del blob."

El desencriptado ocurre en FRONTEND con tableta física conectada.

// backend/app/Controllers/Api/Firmas.php

// Decodifica estructura externa pero NO descifra la firma
public function decodificarEstructuraWacom(string $wacomBlob): array
{
  $json = substr($wacomBlob, strlen('WACOM-STU430-'));
  $estructura = json_decode($json, true);
  
  return [
      'nombre' => $estructura['nombre'] ?? '',
      'dni' => $estructura['dni'] ?? '',
      'fecha' => $estructura['fecha'] ?? '',
      'serial_pad' => $estructura['serial_pad'] ?? 'N/A',
  ];
}

// Extrae PNG si es formato simulado, sino retorna null

      // Lógica para extraer base64 si formato simulado...
  }
  return null; // Para formato real → null (requiere tableta)
}

3.2 Frontend: Dos escenarios de desencriptado
----------------------------------------

Archivo: frontend-nuxt/app/components/Captura.vue

```typescript
const verificarEncriptacion = async () => {
  const PREFIJO = 'WACOM-STU430-';
  
  // 1. Validar prefijo
  if (!blob.startsWith(PREFIJO)) {
    throw new Error('El blob no tiene el prefijo WACOM-STU430-');
  }
  
  // 2. Decodificar estructura externa
  const jsonExterno = atob(blob.slice(PREFIJO.length));
  const estructura = JSON.parse(jsonExterno);
  // estructura = {nombre, dni, firma_encriptada_wacom, fecha}
  
  // 3. Detectar formato:
  
  // CASO A: Formato SIMULADO (JSON anidado con firma_base64)
  if (estructura.firma_encriptada_wacom.startsWith(PREFIJO)) {
    try {
      const jsonInterno = atob(estructura.firma_encriptada_wacom.slice(PREFIJO.length));
      const paquete = JSON.parse(jsonInterno);
      
      if (paquete.firma_base64) {
        // PNG extraído directo - SIN tableta
        resultado.pngBase64 = paquete.firma_base64;
        resultado.raw = JSON.stringify(paquete, null, 2);
      }
    } catch (e) {
      // Error en JSON interno → cae a formato real
    }
  }
  
  // CASO B: Formato REAL Wacom (binario encriptado por dispositivo)
  else {
    resultado.raw = 'Datos binarios encriptados por Wacom STU-430 (requiere descifrado con tableta)';
    
    try {
      const encryptedData = atob(estructura.firma_encriptada_wacom.slice(PREFIJO.length));
      const bytes = new Uint8Array(encryptedData.length);
      
      for (let i = 0; i < encryptedData.length; i++) {
        bytes[i] = encryptedData.charCodeAt(i);
      }
      
      // USAR SDK DE TABLETA FÍSICA PARA DESCIFRAR
      const Crypto = STU().Crypto;
      const decrypted = await Crypto.decrypt(bytes);  // ← CRÍTICO
      
      if (decrypted) {
        const pngBase64 = btoa(String.fromCharCode(...new Uint8Array(decrypted)));
        resultado.pngBase64 = pngBase64;
        resultado.raw = `Descifrado con STU-430: ${decrypted.length} bytes → PNG ${pngBase64.length} chars`;
      }
    } catch (cryptoError: any) {
      resultado.raw = `Formato real Wacom detectado, pero error al descifrar: ${cryptoError.message}`;
    }
  }
  
  resultadoVerificacion.value = resultado;
};
```

4. COMPARATIVA: FORMATO SIMULADO vs REAL
====================================================================

| Característica        | Formato Simulado                                      | Formato Real Wacom                          |
|----------------------|------------------------------------------------------|--------------------------------------------|
| firma_encriptada_wacom | WACOM-STU430-{"firma_base64":"iVBORw0KGgoAAA...","serial":"XYZ"} | Datos binarios AES-256 encriptados por dispositivo |
| ¿Ver sin tableta?    | ✅ Sí - extrae firma_base64 directo en JS            | ❌ No - requiere tableta física             |
| ¿Qué hace frontend?  | Extrae firma_base64 de JSON anidado                  | Llama a STU().Crypto.decrypt() con tableta |
| Caso de uso          | Desarrollo, pruebas, datos migrados                  | Firmas capturadas en operación real        |
| Rol backend          | Extrae metadatos, retorna null para PNG              | Igual - no toca el desencriptado           |

  ↓
RESULTADO: {nombre, dni, fecha, serial, pngBase64, raw}

6. EJEMPLO PRÁCTICO DE DATOS REALES
====================================================================

wacom_blob guardado en BD (formato simulado - desarrollo):
WACOM-STU430-eyJmb28iOiIyMDI2NzgwMyJ9

Decodificado (base64):
{
  "nombre": "Juan Pérez",
  "dni": "12345678A",
  "firma_encriptada_wacom": "WACOM-STU430-{\"firma_base64\":\"iVBORw0KGgoAAAANSUhEUg...\",\"serial\":\"XYZ\"}",
  "fecha": "2026-11-18T10:30:00Z"
}

Al pasar por verificarEncriptacion() frontend:
1. Quita prefijo → JSON externo
2. Parsea → tiene firma_encriptada_wacom
3. Ese campo empieza con WACOM-STU430- → formato simulado
4. Decode interno → encuentra firma_base64: "iVBORw0KGgoAAAANSUhEUg..."
5. Mostrar PNG: data:image/png;base64,iVBORw0KGgoAAAANSUhEUg...

====================================================================
wacom_blob en formato real (producción):
WACOM-STU430-<32 bytes binarios encriptados AES-256 por la STU-430>

Al pasar por verificarEncriptacion():
1. Quita prefijo → JSON externo
2. El firma_encriptada_wacom NO empieza con WACOM-STU430- → formato real
3. Llamar a STU().Crypto.decrypt(bytes) con tableta conectada
4. Si éxito: obtener PNG base64 + "Descifrado con STU-430"
5. Si error: "error al descifrar: [mensaje]"
